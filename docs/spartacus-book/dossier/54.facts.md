## T. Trappole / casi limite

- T1. Un membro `protected` di una classe pubblica può avere un tipo non pubblico: `LaunchDialogService.autoFocusService` è di tipo `AutoFocusService` (non esportato). Una sottoclasse vede il membro, ma non può importare il tipo da `@spartacus/storefront`. — `core-libs/storefront/layout/launch-dialog/services/launch-dialog.service.ts:L17-L17`, `:L30-L30`; `core-libs/storefront/layout/a11y/keyboard-focus/index.ts:L17-L17`
- T2. `@internal` è solo documentale: `ConfigInitializerService.initialize()` resta pubblico nella classe esportata, quindi un'app può chiamarlo pur non essendo contratto stabile. — `core-libs/core/src/config/config-initializer/config-initializer.service.ts:L124-L130`
- T3. Il README del tool breaking-changes mostra `NEW_VERSION = '2211.19'` e cita `renamed-api.json`, mentre `common.ts` usa `'221121_7'` e `renamed-api-mappings.json`. — `tools/breaking-changes/readme.md:L9-L11`, `:L37-L37`; `tools/breaking-changes/common.ts:L12-L17`
- T4. La cartella `docs/migration/221121_7/` non contiene i tre JSON di input (`migration-comments-*.json`, `renamed-api-mappings.json`) presenti in `2211_19/`; il tool in tal caso usa set vuoti. — `ls docs/migration/221121_7 docs/migration/2211_19`; `tools/breaking-changes/common.ts:L22-L31`
