- F22. `MergingSubject` è marcato `// PRIVATE API` e permette di aggiungere/rimuovere dinamicamente sorgenti, esponendole come un unico observable `output$`. — `core-libs/core/src/event/utils/merging-subject.ts:L10-L24`

  >     this.consumer = consumer;
  >     this.bindAllSourcesToConsumer(consumer);
  >     return () => {
  >       this.consumer = null;
  >       this.unbindAllSourcesFromConsumer();
  >     };
  >   }).pipe(share());

- F24. `add(source)` ignora sorgenti già presenti; se c'è un consumer attivo si abbona subito alla nuova sorgente, poi la accoda. — `core-libs/core/src/event/utils/merging-subject.ts:L71-L80`
