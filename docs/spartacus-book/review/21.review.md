## P3 [impreciso] — sezione 9, trappola 14 (e §10, punto "Converter che non scatta")

- Problema: l'errore nasce dentro il `filter` dell'Observable restituito da `getMulti`. `ConverterService.getConverters` però lo consuma con `getLastValueSync`, che si sottoscrive con la sola callback `next`. ## P6 [impreciso] — sezione 8, riga "Normalizer esistenti con membri `protected`"
- Testo nel capitolo: "Normalizer esistenti con membri `protected` (es. `ProductNameNormalizer.reservedSlugCharacters`) | ereditarietà + `useExisting` della sottoclasse"
- Problema: l'esempio scelto non funziona così. Il regex dello slug (`slugRegex`) è un campo `private` che la classe base calcola durante l'inizializzazione dei propri campi, con il valore base di `reservedSlugCharacters`. Lo stesso vale per `sanitizeMultipleSlugChars` con `slugChar`. I campi di una sottoclasse si inizializzano **dopo** quelli della base, quindi ridefinire `reservedSlugCharacters` come campo nella sottoclasse non cambia `slugRegex`. Ridefinire `slugChar` cambia il carattere sostitutivo ma non il regex di compressione dei duplicati. Per personalizzare lo slug bisogna sovrascrivere il metodo `protected normalizeSlug` (o `normalize`).
- Correzione: "Normalizer esistenti con metodi `protected` (es. `ProductNameNormalizer.normalizeSlug`/`normalize`) | ereditarietà + `useExisting` della sottoclasse. Nota: ridefinire solo il campo `reservedSlugCharacters` non ha effetto, perché `slugRegex` (privato) è già calcolato dalla classe base." — `core-libs/core/src/occ/adapters/product/converters/product-name-normalizer.ts:L42-L50` ("protected reservedSlugCharacters = ` !*'();:@&=+$,/?%#[]`; protected slugChar = '-'; ... private slugRegex = new RegExp( `[${this.reservedSlugCharacters.split('').join('\\')}]`, 'g' ); private sanitizeMultipleSlugChars = new RegExp(`${this.slugChar}+`, 'g');"), `core-libs/core/src/occ/adapters/product/converters/product-name-normalizer.ts:L58-L64` ("protected normalizeSlug(name: string): string { ... .replace(this.slugRegex, this.slugChar) .replace(this.sanitizeMultipleSlugChars, this.slugChar);").
