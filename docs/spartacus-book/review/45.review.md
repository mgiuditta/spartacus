## P1 [impreciso] — sezione 3.5 (passo 10)
- Testo nel capitolo: "Il numero di colonne di un sottomenu è `ceil(length / wrapAfter)`"
- Problema: `getColumnCount` non calcola un `ceil`. Restituisce 1 se `wrapAfter` manca o `length <= 0`. Negli altri casi calcola `floor(length / wrapAfter)` e aggiunge 1 solo se il quoziente è già `>= 1` e c'è un resto. Quando `0 < length < wrapAfter` il risultato è quindi `0`, mentre un `ceil` darebbe 1.
- Correzione: "Il numero di colonne è 1 senza `wrapAfter`; altrimenti `floor(length / wrapAfter)`, più 1 se c'è resto e il quoziente è almeno 1. Con meno figli di `wrapAfter` il risultato è 0, non 1." — `core-libs/storefront/cms-components/navigation/navigation/navigation-ui.component.ts:L323-L335`:
  ```
  getColumnCount(length: number): number {
    if (!this.wrapAfter || length <= 0) {
      return 1;
    }
    let subSectionColumns = Math.floor(length / this.wrapAfter);
    if (subSectionColumns >= 1 && length % this.wrapAfter > 0) {
      subSectionColumns += 1;
    }
    return subSectionColumns;
  ```
