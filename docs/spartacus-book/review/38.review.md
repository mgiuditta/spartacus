## P8 [impreciso] — sezione 3.11 (`cms-themes` per ultimo)
- Testo nel capitolo: "`cms-themes` per ultimo, perché le classi `.santorini`, `.lambda`, `.sparta` ridefiniscono le custom property `--cx-color-*` e devono vincere sui default di `:root`"
- Problema: la motivazione riprende il commento di `styles.scss`, ma rispetto a `:root` è imprecisa. Le classi tema stanno sul root component (`app-root`), un elemento diverso da `:root` (`<html>`). Una custom property dichiarata su `app-root` prevale sul valore ereditato da `:root` qualunque sia l'ordine nel foglio. L'ordine conta invece contro le regole che colpiscono lo **stesso** elemento con pari specificità. Ne sono esempi gli override `.cxFeat_*` di `root.scss` (che proprio per questo usano `!important`) e, in generale, qualsiasi altra classe sul root component. Questa è l'analisi corretta che lo stesso capitolo fa in §3.13.
- Correzione: "`cms-themes` va per ultimo perché le sue classi devono prevalere sulle altre regole che dichiarano `--cx-color-*` sullo stesso root component; rispetto ai default di `:root` vincerebbero comunque, perché sono dichiarate su un discendente" — `projects/storefrontapp/src/styles.scss:L27-L29`:

  ```scss
  // the CSS custom properties override the defaults in `:root`).
  @import 'cms-themes';
  ```
  e `core-libs/styles/scss/root.scss:L55-L57`:
  ```scss

  // set this property on the same element with equal specificity and are loaded
  ```
